Upload from your device

Choose files, a folder or a photo. Select the financial year and document type first so each file starts with the right context.

Import from OneDrive

Connect OneDrive in Settings, then browse folders from the upload screen. Import one file or a folder without losing the original location.

Keep the original

TaxVault stores the original document with its evidence metadata. Do not replace a source file with a cropped image when the full document is available.

Find it later

Documents can be filtered by year, type and review state. Use Search when you remember a filename, supplier or document detail.

PAY

When to use Mark as paid

Use it after you have checked that the document represents a payment and you know the payment date, method and amount. It is useful for a receipt or bill that has not already been recorded as a transaction.

TaxVault opens a confirmation form. Check the suggested date and amount, choose the payment method, then select Confirm paid. The document changes to Paid and shows the recorded payment details. TaxVault also creates one linked, uncategorised expense, which you should review and categorise in Income & expenses.

WAIT

When Mark as paid is unavailable

Assign a financial year first. If the document already has multiple or mixed transactions, use Income & expenses instead so each transaction can be checked separately. Do not mark a year-to-date or statement total as a single payment.

DELETE

What Delete does

Delete is permanent and requires confirmation. It removes the original file, the document entry and its review items. Existing OCR extraction, evidence and transactions are kept, but detached from the deleted source document. This cannot be undone.

Before deleting, confirm that the file is a duplicate or was uploaded by mistake. If the document is still processing, wait for extraction to finish. If you only want to change its description, use Edit description instead.

01

Start in the queue

Open Reviews and set the correct financial year. Use Status to focus on pending items and Type to narrow the list. Each card shows the document, extracted-field count and low-confidence values.

02

Read the original first

Open Source document, then preview it in TaxVault or download the original. Check the complete page, not only the text that OCR found.

03

Work field by field

In Document Extraction, compare every OCR value with the source. Confidence is a warning signal, not proof; low confidence means “look closely”.

04

Fill gaps and save corrections

If OCR missed a value, use Add missing details. If it is wrong, use Correct this value and Save Correction. The authoritative correction keeps the original OCR result traceable.

05

Approve, reject or record money

Add notes, then Approve or Reject. If the document should create records, enable Also save transactions in Income & expenses and enter each payment as its own income or expense.

06

Prevent duplicate income

Use Check existing income to search by payment date or cumulative period. Link an existing transaction, or explicitly confirm that this is additional income.

07

Know when it is complete

A completed review has a decision and, when applicable, linked transactions. Reopen it later to inspect notes, corrections and linked transaction details.

Add a transaction

Choose Add, enter a description, select Income or Expense, set the date and AUD amount, then choose the Tax return item. If a category needs a rental property, select it before saving.

Import and check bank rows

Use Import bank file for a supported bank export. Check description, date, direction and amount; importing is not the same as categorising or proving the expense.

Categorise confidently

Apply a tax-return item to one row, or select several rows and apply a category in bulk. Verify Suggest from description before applying it.

Find and filter

Search descriptions, switch between All, Income and Expenses, and sort by description, date, type, year or amount. Attention rows still need action.

Edit or remove

Use Edit to correct description, direction, date, amount, category or property. Delete only when the row is genuinely wrong.

Track recurring income

Add a recurring rule with source, gross amount, day and start/end dates. Preview missing income before backfilling, then pause or resume it.

Properties

Keep property details, ownership, loan information, rental evidence and relevant periods together.

Investments

Capture holdings, disposals, income and cost-base information so capital gains records have their supporting context.

Add or edit the property

Enter the address, reference, ownership and other property details. Use Edit when the address or current information changes. Keep the property linked to the correct financial year when reviewing records.

Current value and readiness

Current value contributes to the portfolio summary. If it shows Not set, look up a reasonable current value using the linked property.com.au check, then enter the value with Edit. Readiness highlights assets missing important information.

Property deductions

Record a deduction for a selected financial year, choose the deduction type such as Capital works deduction (Division 43), enter the amount and add notes. Keep the quantity and supporting schedule consistent with your accountant’s records.

Mortgages

Use Add mortgage to record loan details and balances for the property. The mortgage balance contributes to Total debt; update it when the statement or year-end balance changes.

Rental summary

The summary is built from transactions tagged with a rental tax item and this property. If it is empty, open Income & expenses, edit the transaction, choose the rental category and select the property.

Delete carefully

Delete a property only when it was created by mistake or is no longer meant to be tracked. Before deleting, check linked rental transactions and records so the accountant understands any remaining evidence.

Manage Accountants
  1. Resolve the blockersUse Dashboard readiness and Reviews to finish missing or uncertain items for the selected year.
  2. Prepare the packOpen Accountant Pack, check the included records and confirm that the summary matches the evidence.
  3. Invite or select your accountantIn Accountants, invite the professional or manage an existing connection. Share only the access needed for the work.
  4. Send a short noteTell your accountant which year is ready, what is unusual, and which questions still need their judgement.
  5. Keep the source connectedDo not delete originals after sending. TaxVault is designed to keep evidence, corrections and the handoff traceable.

Finished? Open the Dashboard once more, confirm the correct financial year is selected, and keep the original files in TaxVault after sharing.
